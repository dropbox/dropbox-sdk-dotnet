Class TeamFolderSpaceLimitNotificationTarget

Who receives email notifications when a team folder's usage reaches 80% of its space limit, and when usage reaches or exceeds the limit. These notifications are sent asynchronously, so they can arrive some time after usage crosses a threshold. They are only sent when the caps type is TeamFolderSpaceLimitCapsType.Soft or TeamFolderSpaceLimitCapsType.Hard. Regardless of this setting, team admins and all members with edit access to the team folder are notified when a space limit is added, changed, or removed.
